# 资料提供方的格式

`/wires.csv` 给出厂房在当地分钟区间内的有效变电单元，区间左闭右开。`/room.json` segments 给出单元、起、止、净余量 kW，opening 是柜台本期已确认且已包含在净余量中的流水号。rate_marks 为费率切换分钟。`/trials.json` 提供试车请求，warm 和 run 为连续占用分钟，kw 分别对应两段。分钟基于同一个工作日。
`/reserve` 是物业浏览器表单，填房号、开始分钟、请求号。回页显示柜台工单。浏览器的 `/desk` 按工单号和查询班次返回柜台页。柜台分段金额以 kW 栏为准，受理不等于每一段已确认，early、late 为柜台先后两次班次。撤销记录附在 late 查询页。演练表单按所给输入返回模拟柜台状态。
物业人工预约可从 `/manual-bookings.csv` 得到，是否已进入 opening 要核对柜台票号。未见柜台记录的 M6 为待核实，不计入已确认净余量。
